# PetConnect

Este trabalho propõe o planejamento e o desenvolvimento do PetConnect, uma plataforma de software
voltada para dispositivos móveis. O sistema atuará como um ambiente centralizado,
cujo propósito é intermediar o contato entre doadores/ONGs e cidadãos
interessados em adotar, promovendo a eficiência no fluxo de informações e
potencializando os índices de acolhimento animal.
